Chartroom

Give an agent useful memory without hiding how a connection was made.

Chartroom packages a working GBrain and TypeSafe Jev integration as an MIT-licensed local preview. It captures documents, improves candidate ranking, judges related pages against source evidence, and records graph changes with receipts and history.

Source and quickstartResults and limitations
The system

Capture, judge, connect, inspect.

The useful boundary is between model judgment and durable change. Jev can propose relevance and relationships; Chartroom checks page revisions before publishing selected links, then keeps a receipt so the decision can be inspected or safely resumed.

01 / CaptureSave a document in the local GBrain owner.
02 / JudgeScore search candidates and possible page connections.
03 / ConnectPublish selected graph links with source evidence and revision checks.
04 / InspectRead history and bounded queued work; resume without a new model call.
Small reproducible comparison

Better first results, with a cost.

17/20 → 20/20

Correct first result across 20 questions over the same 30 synthetic notes, Jev off then on. First-pass median search time rose from 34 ms to 150 ms. The reported model input-token estimate was $0.00446, excluding unknown usage from rejected responses.

This is a synthetic demonstration, not a general accuracy or production performance claim. Two enrichment calls failed validation while their documents were still saved.

The release boundary

A local preview, not a hosted brain.

The repository includes synthetic examples, tests, a Linux quickstart, and a fresh-install verification report. Bring your own TypeSafe API key; OpenAI embeddings are optional. Configured providers receive text needed for their calls and bill your own account.

General fact and contradiction enrichment, automatic prose editing, my private editorial controller, and my Android viewer are not in this public package. The live personal brain and its data are not included.
